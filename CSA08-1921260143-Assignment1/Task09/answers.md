# Task 9 — Implementation and Testing

Automated `assert` tests are repeatable and quick to rerun after changes; manual tests are useful for observing the user interface but are easier to forget and take longer. Both are useful. The test program covers standard, high/low quality, zero quantity, fat boundaries, and invalid values. The assumed SNF rule in this implementation rejects negative SNF; the official permitted SNF range should be confirmed with the co-operative. Each test is O(1), and a suite of t cases is O(t) time.
