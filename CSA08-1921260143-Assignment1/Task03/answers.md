# Task 3 — Variables and Constants

Named uppercase constants keep rate changes in one place and avoid unexplained “magic numbers.” Python does not enforce constants; uppercase naming is a convention. Direct literals may need editing in many places, constants centralise edits, and a dictionary groups related rates and supports selecting rate cards. All are effectively O(1) lookup/update; the dictionary has small extra memory overhead, which is negligible for three rates. Multiple assignment swaps values without a temporary variable.
